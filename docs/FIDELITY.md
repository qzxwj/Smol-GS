# 当前实现与论文的对应关系

本仓库依据 `paper/arxiv.tex` 独立实现。本文只描述当前代码，不包含历史实验方案或旧结果。

以下对应关系描述默认 `geometry_mode=neural`。可选的 `explicit` 实验改为每点显式尺度和旋转，
不进行几何量化或几何码率优化；其训练、格式和验证边界见 [EXPLICIT_GEOMETRY.md](EXPLICIT_GEOMETRY.md)。

## 对应内容

| 内容 | 当前实现 |
|---|---|
| 显式 xyz、8维抽象特征和3维缩放控制器 | `scene/gaussian_model.py` |
| Morton 二进制位置编码 | 默认 R=16，48维输入 |
| MLP_oct | 48→64→64→8，隐藏层 ReLU |
| 外观/旋转/尺度 MLP | 增强输入20维、隐藏宽128、三个线性层 |
| Opacity | 末层 Tanh 后取绝对值，两种后端一致 |
| 颜色 | RGB，末层 Sigmoid |
| 旋转和尺度 | 归一化 wxyz 四元数，控制器乘 Sigmoid 调制 |
| 熵上下文 | HAC 二值 3D+XY/XZ/YZ 混合哈希，96维输出 |
| 特征和控制器压缩 | 学习步长、Gaussian prior、算术编码 |
| 坐标压缩 | 全部高斯 min/max 定义 AABB，叶中心量化，碰撞去重 |
| 五阶段训练 | 0–500、500–15k、15k–20k、20k–30k、30k–35k |
| xyz 学习率 | 0.0002→0.00001，指数调度 I=30000 |
| 训练损失 | L1、SSIM、compaction opacity L1、compression NLL |

`base/small/large` 使用 Torch MLP，位置 MLP 学习率按论文为 0.008。`native.json` 使用无偏置的 tiny-cuda-nn FullyFusedMLP 作为外观和位置网络，保留当前选择的位置 MLP 恒定学习率 0.001。后者是稳定性配置，不应称为论文完全一致的基线。所有配置均无额外 MLP 学习率暖启动。

## 需要明确的实现选择

### 增密与剪枝

当前保留屏幕 XY 梯度均值和严格大于 2e-4 的增密阈值。每100步执行 ADC：小高斯原位复制，大高斯按当前相机的预测协方差采样两个子点、移除父点，并将子控制器除以1.6。大小分界为 0.01×训练相机的固定参考半径。

该大小分流策略来自对 3DGS 的适配；论文正文描述的是随机坐标克隆，没有明确给出上述大小分流和缩尺度规则。不能把该适配视为已核对的作者源码。

仅501–15000步增密，501–20000步剪枝。可见观测窗口内平均 opacity<0.005 或持续1000步不可见的高斯会被剪除。可见性使用光栅器 `radii>0`，它是投影预筛选结果，不保证实际像素贡献；窗口长度和该判据不是论文公开的精确实现细节。

不按空间范围、相机半径或控制器大小额外剪枝。不增加体积正则。所有点均满足剪枝条件时抛错，非有限状态也抛错，不静默改规则。

### 初始化与参数化

缩放控制器按 SfM 邻近三点距离平方均值的平方根初始化，以 `exp(log_s)` 保持正值。抽象特征使用标准差0.01的正态初始化。原生 MLP 使用固定种子的原生 Xavier 初始化；Torch MLP 使用 PyTorch 默认初始化。

xyz 学习率不额外乘相机半径或包围盒尺度。`scene_extent` 是训练相机中心到其均值的最大距离乘1.1，用于当前增密大小分流，不是场景几何边界，也不用于裁剪坐标。

### 量化与包围盒

第四、五阶段训练使用 uniform(−Δ/2, Δ/2) 噪声，评估和编码使用 round(x/Δ)×Δ。NLL 使用互不重叠的半步长箱宽，与 HAC 算术流一致；论文正文的积分端点写法存在差异，配置中的 `rate_bin_half_width` 明确记录该选择。

位置编码包围盒在 ADC 周期更新，20001步固定独立的哈希归一化范围，30001步按所有高斯的 min/max 固定坐标网格并冻结 xyz。没有分位数裁剪、范围外强制删除或自动提高 R。

量化导致的碰撞删除比例超过 `coordinate_max_collision_fraction` 时中止且不更改拓扑。默认0.5是工程故障保护阈值，不是论文超参数或质量保证。

熵上下文的输入坐标 detach；渲染仍对 xyz 求梯度。这是当前梯度路径选择，不能断言与作者未公开的自动微分细节一致。

### 存储与评估

当前检查点为 v3、压缩包为 v6，要求显式记录 `opacity_activation=abs_tanh`。仅接受当前配置字段，没有旧 opacity、中心化、修复参数或旧配置迁移分支。

压缩包保存网络、按位打包的二值哈希、坐标和属性码流及元数据。全部 ZIP 开销计入 Size。CUDA 算术流依赖匹配的上下文后端，不静默切换浮点上下文。保留文件级 SHA-256 校验，不存储或校验各块量化整数的 SHA-256。

CPU 属性编码在模型上下文的推理精度和设备上生成整数符号，分块和算术编码共用这些整数；CDF 仍用 float64 计算。CPU 解码恢复 int64 符号后，直接以模型步长的 dtype 和设备执行乘法重建属性。整数逐元素往返比较放在回归测试中。保留 GAC1 码流及 v6 容器格式；旧 v6 包中的整数 SHA 字段不再参与解码，旧编码器因重复量化写入错误整数的包仍需要从检查点重新导出。

LPIPS 使用 Inria 3DGS VGG v0.1，RGB [0,1] 直接输入，normalize=False。该口径已由独立参考数值测试，不等于核实了作者未公开的评估源码。

`results/` 和 `official_snapshot/` 中的 CSV 仅是作者公开参考结果。模型初始化、编解码和流程测试通过，不代表已经复现论文质量或大小。
