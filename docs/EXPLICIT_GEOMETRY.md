# 显式几何：第一步实现边界

启用方式：`--geometry-mode explicit` 或 `--config configs/explicit.json`。
默认仍为 `neural`，原版训练和存储行为保留作为对照。

## 表示与训练

- 每点 `log_scales[N,3]` 经 exp 得到物理尺度；不再乘 MLP 调制项。
- 每点 `rotations[N,4]` 保存原始 wxyz 四元数，按单位四元数初始化；渲染前归一化。
- 原始四元数范数不超过 1e-12 时渲染为单位旋转，避免零四元数进入 CUDA 光栅器。
- 移除两个几何 MLP；特征、位置编码、颜色和 opacity 分支的公式保持原定义。
- 熵 MLP 仅输出特征的均值、标准差、步长，维度为 `2*feature_dim+1`。
- 特征压缩阶段仍使用原特征噪声量化和 Gaussian NLL。几何没有噪声量化、标量量化、VQ 或码率损失。
- 显式尺度/旋转分别使用固定学习率 0.005/0.001，对应本地 RDO 的几何参数学习率。其余学习率与原配置一致。

为支持相同 seed 的初始化对照，模型构造仍消耗原几何头初始化所需的随机数，
但不注册、训练或保存这些头。熵网络共享隐藏层和特征对应输出行也与原版保持相同初始化。
删除尺度量化噪声后，后续训练的随机数消耗轨迹会变化；相同 seed 不代表整个训练轨迹相同。
原始尺度初始化在原版中还乘过 sigmoid 调制，因此两版实际初始几何并不相同。

## 拓扑与保存

所有逐点参数通过同一个 `point_parameter_names` 列表重排。
clone 复制旋转，split 继承父旋转、按父协方差采样位置并将尺度除以 1.6。
剪枝、坐标 Morton 排序和碰撞去重同步处理旋转与 Adam 状态；新生点动量清零，幸存点保留。
坐标冻结后，尺度和旋转继续学习。

显式检查点版本为 v4-explicit，存储所有参数、Adam、阶段迭代和随机数状态。
格式与配置的几何模式必须一致，不提供 neural 到 explicit 的检查点转换。
从训练检查点续训；已解码压缩包只用于推理。

为使完整五阶段训练仍能保存并独立解码，v7-explicit 包将 log_scales 和原始旋转
按坐标编码顺序保存为 FP32 NPY 数据，ZIP 压缩不会损失精度。
特征与其熵上下文继续使用原编码方式。几何没有新增有损压缩，实际字节数全部计入 Size。

## 验证

`tests/test_explicit_geometry.py` 检查：

- 初始化对照、独立学习率及优化器参数覆盖；
- 跨视角/阶段、特征变化和训练噪声下的几何一致性；
- mask、空集合、单点及近零四元数；
- 尺度/旋转梯度、特征码率不依赖几何；
- Torch/CUDA 渲染反传；
- clone/split/prune 及一阶、二阶、AMSGrad 动量迁移；
- 坐标排序去重与冻结后的可训练参数；
- 保存恢复的逐项精确性、随机数和后续更新；
- 缩短五阶段训练及 CPU/CUDA 编码、Torch/tiny-cuda-nn 网络的独立解码渲染对照。

CPU 续训检查逐位一致；CUDA 状态恢复也逐位检查，后续 CUDA 反传更新允许
`atol=1e-8, rtol=2e-6`，因为原有原子归约不保证逐位确定性。
这些检查验证实现链路，不代替真实场景 35k 训练与质量评估。
